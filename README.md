# DSA-UNIT-3-LINKLIST
# Movie Ticket Management System Using Linked List

## Project Overview
A menu-driven C++ application that manages movie ticket records using a singly linked list.

## Features
- Add a movie ticket
- Display all tickets
- Search tickets by ticket number
- Delete a ticket
- Update a movie name
- Exit the application

## Technologies Used
- C++
- Singly Linked List
- Structures and Pointers
- Dynamic Memory Allocation

## Conclusion
This project demonstrates the use of a singly linked list for managing records in C++. It provides practical experience with pointers, structures, dynamic memory allocation, and linked-list operations.
